# Security Policy

This is **sadad-hub — Sadad detection content**, part of the Qas Security Suite.

Security policy and disclosure process are maintained at the suite level:

**[bosoud/qas — SECURITY.md](https://github.com/bosoud/qas/blob/main/SECURITY.md)**

In short:

- **Do not file public issues for security vulnerabilities.** Open a private GitHub Security Advisory on this repo (`bosoud/sadad-hub`) instead, or use the suite's private channel.
- Acknowledgment within 72 hours.
- 90-day coordinated disclosure default.

Hardening guidance and the suite's threat model live in [bosoud/qas SPEC/security.md](https://github.com/bosoud/qas/blob/main/SPEC/security.md).
